# SnapUI — полный гайд (RU)

## Установка и первый захват — 2 минуты

```bash
npx snapui
```

1. Откроется Chrome (или подключимся к твоему — см. ниже).
2. Введи URL, если нужно (например `https://stripe.com`).
3. **Кликни любой элемент** на странице — сиреневая рамка показывает, что захвачено. `Esc` — отмена.
4. Ответь на 3 вопроса: имя компонента, фреймворк, стилизация.
5. Укажи папку вывода — готово, файлы созданы.

## Подключение к своему Chrome (с твоими логинами)

Если хочешь захватывать элементы на сайтах, где ты залогинен:

```bash
google-chrome --remote-debugging-port=9222   # macOS: open -a "Google Chrome" --args --remote-debugging-port=9222
```

Затем запусти `snapui` — когда прямой запуск не удастся, он предложит attach к порту 9222.

## Что именно генерируется

- `components/<Имя>.tsx | .vue | .svelte | .html` — компонент с чистой разметкой
- `styles/<имя>.css` — только реальные, не дефолтные стили (без мусора `margin: 0` × 200)
- `storybook/<Имя>.stories.tsx` — сторис для React-компонентов

SnapUI переиспользует осмысленные классы с сайта, а безликим элементам даёт BEM-имена вида `hero-section__h1`.

## Стилизация

| Режим | Что получишь |
|---|---|
| CSS | чистый CSS-файл, упорядоченные свойства, шортхенды (`padding: 8px 16px`) |
| CSS Modules | то же + `styles[...]` в TSX |
| SCSS | тот же CSS, готов к SCSS-проекту |
| Tailwind | utility-классы прямо в разметке, arbitrary values для нестандартных значений |

## LLM-полировка (опционально, твой ключ)

```bash
npx snapui config
# Base URL:  https://api.openai.com/v1   или   http://localhost:11434/v1 (Ollama)
# Key:       sk-...
# Model:     gpt-4o-mini
```

После захвата CLI спросит, отполировать ли код. Всё локально, ключ хранится в `~/.snapui/config.json`.

## Решение проблем

- **Chrome не найден** → SnapUI сам скачает managed Chromium в `~/.snapui/browser` (один раз, ~150 МБ).
- **Захват отменяется сразу** → страница перезагрузилась? Просто захвати заново.
- **Слишком много узлов** → кликай более мелкий элемент; лимит — 400 узлов на захват.
- **SVG** → инлайнится как есть, стили пишутся на обёртке.
